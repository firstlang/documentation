# First Documentation

This repository contains the documentation source for the First language website.

## Structure

- `src/` contains the handbook pages.
- `+Reviews/`, `+Ambiguity-Ledgers/`, and related `+` folders contain working notes and review material.
- `assets/` contains repository-level README assets.

## Contributing

Keep changes concise and consistent with the surrounding documentation. Use tabs in First code examples, and use Allman-style grouping for First examples.
