# Language Examples

This section contains complete, independently compilable First fragments. The examples are inputs for compound parser tests and editor visualizations rather than a progressive tutorial.

Each example uses ordinary serialized First source. Editor-generated glyphs and other derived presentation do not appear in the code blocks.

The collection includes ordinary programs, composed programs, and realistically dense programs. Dense examples exercise difficult editor layouts while remaining idiomatic, readable, and suitable for line-by-line debugging.

## Fixture Rules

Every fenced `first` block in this section must:

- Compile independently.
- Contain only raw First source.
- Use idiomatic formatting.
- Avoid undeclared application-specific dependencies.
- Demonstrate plausible program code rather than parser torture or code golf.
